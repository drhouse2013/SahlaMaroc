## Procédure par fichier
1. Comparer avec la version fr (même `translationKey`) : faits, chiffres, dates, liens, avertissements identiques.
2. Vérifier titre (≤ 70 car.) et description (50-160 car.) naturels pour la recherche locale.
3. Corriger la langue (registre, termes administratifs locaux), sans changer les faits.
4. Une fois validé : supprimer `machineTranslated: true` du frontmatter, puis `npm run check:content` et `npm run build`.
5. Quand toute une langue est validée : l'ajouter à `INDEXABLE_LOCALES` dans `site.config.mjs`.

Priorité : guides MRE (catégories retour, demarches, immobilier, money), puis calculateurs, puis le reste.
